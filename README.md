SOLMARINA is an original top-down 2D open-world crime game: explore the city of Solmarina Bay on foot and by car, steal cars, outrun the police across a 0–5 star wanted level, and play 6 story missions — with synthesized WebAudio sound and music, zero external libraries, zero network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
